ソフトウェアの企画・開発および販売

レイノワークスは、代表レイノが個人事業主として開業したソフトウェアブランドです。主力製品の動画ダウンローダー「Megrab Studio」をはじめ、macOS / Windows / Android 向けのソフトウェアを自ら企画・開発し、販売・運用まで行っています。

開発スタイルは、課題の言語化と AI エージェントの活用。仕様の決定・要件定義・検収を本人が担い、実装を AI エージェントと協働で進めることで、個人として複数プラットフォーム向けの製品を並行して開発・運用しています。開発体制については Zenn でも公開しています。

Hodozip

Windows 向けのアーカイブ解凍・圧縮ソフト。ダブルクリックでその場に解凍する往年のアーカイバ風の操作感で、解凍は 13 形式に対応。ZIP / 7z の作成（ZIP は AES パスワード対応）と、管理者権限が不要なユーザー単位インストーラー、GitHub Releases を確認する自動アップデートを備えています。文字化け対策あり。通常の解凍・圧縮では通信せず、アップデート確認時のみ GitHub へ接続します（設定で無効化可能）。テレメトリなし・広告なし。MIT ライセンス。

レイノワークスとはどのような事業ですか？

代表レイノが 2026 年 10 月 25 日に開業した個人事業です。「ソフトウェアの企画・開発および販売」を主な事業として、製品の企画・開発から販売・運用までを個人の一貫した体制で行っています。

どのようなソフトウェアを開発していますか？

主力製品は YouTube / ニコニコ動画 / BiliBili / TikTok に対応する動画ダウンローダー「Megrab Studio」（macOS / Windows / Android）と、Windows 向けディスク容量ビューアー「Yohaku（よはく）」です。このほか、Windows 向けのアーカイブ解凍・圧縮ソフト「Hodozip」など無料・オープンソースのツールも公開しています。詳しくはWORKSをご覧ください。
