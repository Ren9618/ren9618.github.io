Hodozip

Windows 向けのアーカイブ解凍・圧縮ソフト。ダブルクリックでその場に解凍する往年のアーカイバ風の操作感で、解凍は 13 形式に対応。ZIP / 7z の作成（ZIP は AES パスワード対応）と、管理者権限が不要なユーザー単位インストーラー、GitHub Releases を確認する自動アップデートを備えています。文字化け対策あり。通常の解凍・圧縮では通信せず、アップデート確認時のみ GitHub へ接続します（設定で無効化可能）。テレメトリなし・広告なし。MIT ライセンス。

MacUtl

AviUtl 風の動画編集ソフト「NeoUtl」を macOS に移植した非公式フォーク。プレビュー／タイムライン／プロパティを 1 つのウィンドウに集約したレイアウトで、日本語 IME に対応しています。2026 年 11 月 12 日公開。対応環境は macOS 27.0 以降・Apple Silicon のみ。ベースの NeoUtl がプレアルファ版のため、発展途上のソフトです。AGPL-3.0 ライセンス。

FAQ

どのようなソフトウェアを開発していますか？

主力製品は YouTube / ニコニコ動画 / BiliBili / TikTok に対応する動画ダウンローダー「Megrab Studio」（macOS / Windows / Android）と、Windows 向けディスク容量ビューアー「Yohaku（よはく）」です。このほか、Windows 向けのアーカイブ解凍・圧縮ソフト「Hodozip」など無料・オープンソースのツールも公開しています。詳しくはPRODUCTSをご覧ください。

Megrab Studio はどこで購入できますか？

公式サイトからご購入いただけます。Free プラン（¥0）のほか、Pro は月額 ¥390・年額 ¥2,480・買い切り（v1.0 系）¥5,980 の3つの提供形態があります。購入方法・30 日間の無償体験・返金ポリシーの詳細は公式サイトをご確認ください。
